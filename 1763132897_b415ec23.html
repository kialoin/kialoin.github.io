核心要点总结

闭包定义：有权访问另一个函数作用域中变量的函数。

关键特征：内部函数可访问外部函数的变量和参数，但外部函数不能访问内部函数的变量。

主要用途：数据封装、模块化、回调函数和事件处理。

注意事项：可能导致内存泄漏，需谨慎使用，避免过度嵌套。

关键信息提取
核心概念

闭包的本质是函数能够访问并"记住"其外部作用域中的变量，即使外部函数已经执行完毕。

代码示例

function outer() { let x = 1; return function inner() { return x; }; }
